# 分屏（M5）

依据：方案 5.11"分屏"、5.1（窄窗口、返回会话时恢复分屏）、5.3（会话右键菜单、删除后分屏中这一栏关闭）、5.8（Esc）、
5.9（右栏跟随焦点所在的一侧）、5.15（F8）、第 6 节（打开过的会话一直开着；Mori 自己保存的界面状态）。
拖会话引用见 [session-refs.md](session-refs.md)；会话面板本身见 [chat.md](chat.md)；左栏与右栏的外框见 [layout.md](layout.md)。
拖放与分屏的交互移植自 `demo/session-actions.js`、`demo/chat-pane.js`、`demo/resize.js`（只移植交互，不沿用代码）。

## 用到的事实

| 事实 | 影响 |
| --- | --- |
| 本次运行里打开过的会话一直开在后台进程里，直到归档、删除或退出（M3，照 Claude 桌面版） | 分屏只是让两个会话同时显示；关闭一栏只是不再显示它，生成照常进行，不发任何命令 |
| 每个打开的会话在界面里各有一份对话流、草稿、引用芯片、批准卡、询问卡、排队区、权限和上下文用量（M1–M4） | 分屏的两栏各自是完整的会话面板，互不影响 |
| 中栏没有显示的会话本轮结束时标"Unread"（M3） | "显示"改为：在任一栏里（分屏时两栏都算） |
| 浏览器原生拖放：拖动时按 Esc 或拖出窗口就取消，`dragend` 一定会来 | 放下提示随 `dragend` 消失，不会留在屏幕上 |

## 中栏的两种样子

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 单栏 | 默认；关闭分屏之后 | 一个会话面板（M1–M4 的样子） | 把会话拖到中栏左半边或右半边；会话右键菜单"Open in split view" |
| 分屏 | 你在中栏放下了一个不在中栏的会话，或选了"Open in split view" | 左右两栏，各自有标题行（"项目名 › 会话名"、右栏开关、"Close pane"；2026-10-26 前还有协作开关）、对话流、阶段行、批准卡、询问卡、排队区和输入框（下面一行有权限、选择范围、Effort、上下文用量和发送按钮，2026-10-21 起从标题行移来），草稿各自保存；两栏之间一条分隔线；新放进来的那一栏得到焦点，焦点放进它的输入框 | 见下 |
| 焦点所在的一栏 | 你在这一栏里按下鼠标（含右键），或键盘焦点进入这一栏 | 标题行底色变浅蓝、下边一条强调色的线（只在分屏时）；侧栏里它的会话行高亮，另一栏的会话行浅色标出 | — |

最多两栏。中栏没有会话（"Open a folder"）时拖进来或选"Open in split view"等于打开这个会话（单栏）。

## 拖会话到中栏

拖的东西：侧栏里的会话行（已归档的除外），或分屏标题行上的会话名。放下前在中栏上浮一层半透明的提示（不挡住拖放）。

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 拖到左半边 / 右半边 | 拖的会话不在中栏；鼠标在中栏左半边或右半边（输入框之外） | 单栏时那半边、分屏时那一栏上一层提示"Drop to open in split view on the left" / "Drop to open in split view on the right" | 松开：单栏时在这一侧分屏打开；分屏时换掉这一侧那一栏（被换掉的会话照常开在后台） |
| 拖已在中栏的会话 | 拖的会话已经显示在某一栏 | 那一栏上一层提示"Already open · Drop to switch to this pane" | 松开只把焦点切到那一栏，不改分屏 |
| 中栏没有会话 | 中栏是"Open a folder" | 整个中栏上一层"Drop to open this session" | 松开打开它 |
| 拖到输入框上 | 拖的会话不是这一栏的会话 | 引用的提示，见 [session-refs.md](session-refs.md) | 松开引用 |
| 取消 | 拖出窗口、Esc、在没有提示的地方松开 | 提示消失，什么都不变 | — |
| 打开中 | 放下的会话本次还没打开 | 那一栏立刻出现，按钮位置"Starting…"；需要时先弹信任询问（与点会话行相同） | — |

拖动中被拖的会话行变淡。设置页里不能放下（没有中栏）。

## 两栏里的操作

| 操作 | 结果 |
| --- | --- |
| 在侧栏点一个不在中栏的会话（或在会话行上按 Enter） | 它换掉焦点所在的那一栏；分屏不变 |
| 在侧栏点已在某一栏的会话 | 焦点切到那一栏 |
| 项目行的 +（2026-10-26 起取代"New session"，[sessions.md](sessions.md)"项目行的 +"）、Ctrl+N、"Open folder…" | 新会话出现在焦点所在的那一栏 |
| 标题行"Close pane"（×，只在分屏时有；悬停"Close pane (doesn’t stop the response)"） | 回到单栏，另一栏占满中栏并得到焦点；关掉的会话照常在后台生成（侧栏"Running"，本轮结束标"Unread"，批准请求照常让侧栏显示"Needs approval"、任务栏闪烁） |
| 归档、删除分屏中的会话 | 这一栏关闭，另一栏占满中栏（方案 5.3） |
| Esc | 先关浮层；没有浮层时只停止焦点所在的那一栏（焦点要在这一栏里，方案 5.8） |
| Alt+1 / Alt+2 / Alt+3 | 焦点所在的那一栏最前面的批准卡 |
| F8 | 报告里的"Current session"是焦点所在的那一栏；分屏时另记一行"Split view: Left: <名字> · Right: <名字> (focus in the left pane)"（焦点在右边时"right"） |
| 去设置页再回来 | 分屏、比例、焦点、两栏的滚动位置和草稿都在（方案 5.1） |
| 后台进程意外退出、重新载入 | 两栏各自显示退出横幅、各自重新打开（M1、M3 的做法） |
| 界面重新加载、重启 | 不恢复分屏（M3 起启动后不自动打开会话）；分隔线的比例保留 |

## 分隔线（分屏中线）

| 项 | 做法 |
| --- | --- |
| 范围 | 两栏各至少 280px |
| 鼠标 | 拖动；拖动中整窗光标为 col-resize、不选中文字 |
| 键盘 | Tab 可以聚焦（`role="separator"`，读屏名称"Resize panes"，`aria-valuenow` 为左栏像素宽度）；← → 每次 20px |
| 双击 | 两栏各一半 |
| 保存 | 左栏占中栏的比例存在本机（`localStorage` 的 `mori.layout`），重启后保留；窗口变化时按比例算 |

## 右栏（方案 5.9：跟随焦点所在的一侧）

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 跟随焦点 | 焦点切到另一栏 | 右栏换成那一栏会话的改动或文件（各会话各自记住右栏的视图和开关，M4） | — |
| 右栏开关 | 每一栏标题行上都有（读屏名称"Toggle changes"，悬停"This session’s changes"） | 按下状态表示"这一栏有焦点时右栏是否打开" | 点它：焦点先切到这一栏，再开关右栏。用鼠标主键按在开关上时，焦点在这一下点完（或在别处松开）时才切到这一栏，不在按下时（"焦点所在的一栏"的例外，2026-10-22）：按下就切的话右栏先换成这一栏的开关状态、两栏变宽，开关被挤到别处，松开时不在开关上，这一下就点空了。右键照常在按下时切；键盘焦点进入开关时照常切。同一组的"Close pane"也这样（2026-10-22 最终审查后加：它在开关旁边，会被同样挤走；那时顶栏还有协作开关，2026-10-26 移进模型菜单）：点完才切焦点；点了"Close pane"时那一栏已经关上，另一栏得到焦点（上面"Close pane"一行） |
| 放得下 | 中栏放得下两栏各 280px 加最窄的右栏（260px） | 右栏贴在右边，最宽不超过"窗口 − 左栏 − 560px"（2026-10-26 走查 M23 起没有另外的 800px 上限） | 拖右栏分隔线；"Expand" |
| 右栏展开（2026-10-26 走查 M23） | 右栏贴在右边时你点了"Expand"（[layout.md](layout.md)"右栏展开"） | 两栏一起藏起（都保持挂载），右栏占满左栏右边；右栏跟随的仍是焦点所在的那一栏 | "Collapse"、"Close panel"回到两栏；点侧栏另一栏的会话行：焦点切过去，那个会话没有展开时两栏照常显示 |
| 放不下 | 分屏时中栏放不下两栏各 280px 加最窄的右栏 | 右栏先收起（方案 5.11"两栏各不足 280px 时先收起右栏"）；有改动时也不自动打开 | 点右栏开关：右栏浮在两栏上层（与窄于 800px 时相同），× 或再点开关收起 |
| 浮在上层（2026-10-26 补，走查 M23） | "放不下"时你点了右栏开关 | 右栏浮在两栏上层，两栏宽度不变；顶部没有"Expand" / "Collapse"；最宽到"窗口 − 60px"（拖分隔线，原来最宽 800px）；窗口变宽、回到贴在右边时"Expand"恢复 | 拖右栏的分隔线；× 或再点开关收起 |
| 回到单栏或窗口变宽 | — | 右栏回到你原来的开关状态（贴在右边） | — |

## 窄窗口

| 窗口宽度 | 结果 |
| --- | --- |
| ≥ 1024px | 左栏展开；分屏时右栏按上表放得下才贴在右边 |
| < 1024px | 左栏收起为图标栏（M1）；例如 1000px 宽时两栏加右栏仍放得下 |
| 最小 800px | 图标栏 60px，两栏各 370px，右栏收起（点开关时浮在上层）；没有内容被裁掉：标题行的会话名约 216px（2026-10-26 WP-09 合入时 `m5-app` titleRoomCheck 量的；之前顶栏还有只剩状态点的协作开关，约 195px），输入框下面一行放得下（[models.md](models.md)"窄栏"） |

## 界面测试用的标识

| 元素 | 标识 |
| --- | --- |
| 中栏 | `.center`，分屏时 `data-split="true"` |
| 一栏 | `.pane-slot[data-tab]`，显示中的带 `data-side="left"` / `"right"`（单栏时 `"single"`），焦点所在的带 `data-focused="true"` |
| 标题行的会话名 | `[data-testid="session-title"]`（按钮，可拖、可右键；不占 Tab 停靠点，键盘用侧栏会话行上的同一个菜单；"从输入框 Shift+Tab 回到会话树"的次数不因它变，2026-10-22 起是 6 次（多了顶栏的协作开关），2026-10-26 开关移进模型菜单后是 5 次，见 [sessions.md](sessions.md)"键盘"） |
| 关闭这一栏 | `[data-testid="close-pane"]`（读屏名称"Close pane"） |
| 分屏中线 | `[data-resize="split"]` |
| 放下提示 | `[data-testid="drop-hint"]`，`data-kind` 为 `split` / `focus` / `open` / `reference` |
| 侧栏里另一栏的会话行 | `.session-item.in-split` |
| 右栏展开（2026-10-26） | `.app[data-right-expanded="true"]`（这时 `.center` 是 `display: none`）；按钮在右栏顶部，读屏名"Expand" / "Collapse" |

## 反例

- 关闭分屏不停止正在生成的会话：关掉后它在侧栏仍是"Running"，本轮照常结束、标"Unread"，后台进程没有收到停止命令。
- 在左栏按 Esc 只停止左栏，右栏照常生成。
- 拖已在中栏的会话不会出现第三栏，也不会把同一个会话放进两栏。
