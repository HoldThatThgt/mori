# 工作回顾（M7）

依据：方案 5.14、5.1（左栏导航"工作回顾"、独立页面顶部"返回会话"）、第 4 节"选区反馈、F8 界面问题 · Mori · 记录、收件箱、导出"、
第 6 节（`feedback.ts`；Mori 自己只保存界面状态、反馈和 F8 报告）。
读的记录：对内容的反馈是 [selection.md](selection.md) "反馈"存下的 JSON；界面问题是 [f8.md](f8.md) "保存的内容"里的报告。
回到原位置照 [selection.md](selection.md) "回到原位置"。

2026-10-21 负责人决定（开工时问的）：

- **三级结构**，与现有界面一致：左栏顶层入口"工作回顾"；中栏是列表，每条一段摘要；点一条在右栏打开详情。
- **已处理**是你自己打的勾，意思是"这一条我处理过了"（例如问题在下一轮改好了）；只让它变淡或不列出，不删除任何东西。
  用"隐藏已处理"开关筛掉：默认全部显示，已处理的变淡并标"已处理"；打开开关后不列出；开关的选择重启后还在。
- **已处理的标记**记在 Mori 本机的界面状态里（与"已归档"相同），反馈和报告文件不改。
- **界面问题的数据在一个文件夹里**：`<userData>\ui-issues\`，这台电脑的这个用户一份，所有项目和会话共用，每份报告的 Markdown 和截图都在里面。
  要交给别人时把这个文件夹打成一个 zip，或者用"导出"。导出只写一个 `.md`，截图链接指向原来的 PNG，不复制截图。

| 状态 | 来源 | 必须可见 | 可做的操作 |

| 工具行 | — | "隐藏已处理"开关；"导出为 Markdown…"；"打开文件夹" | 见下 |

| 列表 | 读到的记录 | 按记录的时间从新到旧，每条一行摘要（见下）；没有分页 | ↑ ↓ 在行之间移动焦点；Enter 或点击打开详情 |
| 何时重新读 | 打开工作回顾；页面开着时你保存了新的反馈或 F8 报告；点"重新读取" | 新记录出现在最上面；不监视文件夹，别的程序写进来的要下次打开才看到 | — |

**一行摘要**

| 记录 | 必须可见 |
| --- | --- |
| 反馈 | 你的期望（最多 2 行）；原文的第一行（截断，引用样式）；来源和时间："<会话名> · 回复里的选区" / "<会话名> · 整条回复" / "<文件> 第 a–b 行"，时间"10-20 14:03"（本地时间，不是今年的带年份） |
| 界面问题 | "哪里不对"（最多 2 行；没有填写时用"你期望什么"）；时间；没有截图时标"没有截图" |
| 已处理 | 整行变淡，标"已处理" |
| 选中 | 整行高亮（右栏显示它的详情） |
| 读不出来 | 一行"读不出这份记录：<文件名>"和原文（JSON 坏了、字段不对，或报告缺"哪里不对"等标题）；可以选中、标已处理 |

会话名用侧栏现在的名字（改过名的显示新名字）；找不到会话时用记录里的名字。文件按反馈时会话的工作目录显示相对路径，不在工作目录里的显示完整路径。

**只认 Mori 写的文件**：反馈文件夹里只列 `.json`，界面问题文件夹里只列名字是报告时间格式（`YYYY-MM-DD-HHmmss.md`，同一秒的 `-2`、`-3`）的 `.md`；
别的文件（例如你导出到这个文件夹里的 `.md`、zip）不列出。

## 隐藏已处理与已处理

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 开关关着（默认） | 本机界面状态 | 全部记录；已处理的变淡并标"已处理" | 打开开关 |
| 开关开着 | 你打开了开关（两个分节共用一个开关，重启后保留） | 已处理的不列出；分节上的数字不变（一直是未处理的条数） | 关掉开关 |
| 标为已处理 | 你在详情里点了"标为已处理" | 这一行变淡并标"已处理"；开关开着时这一行马上不列出，右栏的详情还在，按钮变成"标为未处理" | 标为未处理 |
| 标为未处理 | 你在详情里点了"标为未处理" | 回到平常的样子 | 标为已处理 |
| 保存 | 本机 `localStorage`（`mori.review`），按"文件夹/文件名"记 | 重启后还在；本机存储被清掉时全部回到未处理 | — |

## 回到原位置（反馈）

只在你点"回到原位置"时检查（不预先读会话、不读文件）。打开会话与在侧栏点它相同：已经开着的直接显示，已归档的先恢复，
分屏时放进焦点所在的一栏；之后的滚动、高亮照 M4 点芯片回到原位置。

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 回复里的 | 锚点：会话文件、条目 id（反馈时回复还在生成就没有 id，用消息时间） | 先确认那条回复还在：会话开着时看对话流，没开着时读会话文件（`session.read`）；在的话中栏换回会话，滚到那条回复，高亮约 4 秒（选区高亮原文，整条回复高亮整轮） | 在侧栏点"工作回顾"回来，选中的还是这一条 |
| 文件里的 | 锚点：路径、内容哈希、行范围；反馈时所在的会话 | 打开反馈时所在的会话，右栏打开阅读器：哈希没变滚到原来的行，变了找原文，找不到时阅读器顶部"原文已变化 · 引用时的原文："；文件不在了显示"文件已被删除或移动"（同 M4） | 同上 |
| 正在检查 | 读会话文件中 | 按钮显示"正在打开…"，不可再点 | — |
| 回复不在了 | 会话当前的分支上找不到这条回复 | 留在工作回顾，详情里"原文已变化：会话里找不到这条回复了"；引用的原文仍在详情里 | — |
| 原会话已删除 | 会话列表读完了、里面没有它，本次也没有打开它；或读会话文件时文件不在 | 详情里"原会话已删除"，"回到原位置"不可用；引用的原文仍在 | — |
| 原会话没有保存 | 记录里没有会话文件 | 详情里"原会话没有保存，无法回到原位置"，按钮不可用 | — |
| 会话列表没读好 | 侧栏的会话列表还在读或读取失败，原会话也没有打开 | 留在工作回顾，详情里"会话列表还没读完，稍后再试" / "会话列表读取失败，无法打开原会话" | 稍后再点"回到原位置"（成功后说明消失） |
| 打开失败 | 会话打开报错 | 中栏是这个会话，会话横幅显示原文（同在侧栏点它） | 重试（会话横幅） |
| 后台进程已退出 | — | 按钮不可用，说明"后台进程已退出，先重新载入" | — |

检查的结果只记在这次运行的内存里。

## 导出为 Markdown

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 可以导出 | 这一节有列出的记录 | "导出为 Markdown…"可用 | 导出 |
| 没有可导出的 | 这一节一条都没列出（空，或都已隐藏） | 按钮不可用 | — |
| 选位置 | 你点了导出：主进程的保存对话框 | 标题"导出对内容的反馈" / "导出界面问题"；默认文件名 `对内容的反馈-<YYYY-MM-DD>.md` / `界面问题-<YYYY-MM-DD>.md`，默认放在"文档"里 | 保存；取消（什么都不变） |
| 已导出 | 主进程写完文件 | 工具行下面"已导出 N 条到 <路径>"和"打开所在文件夹" | 打开所在文件夹（资源管理器里选中导出的文件） |
| 导出失败 | 主进程写文件报错 | "没有导出："+ 原文 | 再导出 |

**导出哪些**：这一节现在列出的记录（"隐藏已处理"开着时不含已处理的），顺序与列表相同，每条注明"未处理"或"已处理"。

**导出的内容**（临时默认值，见 defaults.md）：

- 开头：`# 对内容的反馈` 或 `# 界面问题`，下一行导出时间、条数（"共 N 条：未处理 a 条，已处理 b 条"）。
- 反馈每条一节 `## <序号>. <时间> · <未处理/已处理>`：来源（会话名、范围或文件和行、会话文件、工作目录）、
  `### 你希望得到的结果`、`### 引用的原文`（每行前加 `> `）。
- 界面问题每条一节 `## <序号>. <时间> · <未处理/已处理>`：报告文件的完整路径，然后是报告原来的各节（`### 哪里不对`、`### 你期望什么`、
  `### 截图`、`### 当前界面`、`### 最近的操作`、`### 版本`，标题降一级）。截图链接写成从导出文件所在的文件夹到原来那张 PNG 的相对路径
  （每一段按网址编码；导出到 `ui-issues` 文件夹里时就是文件名，连同文件夹打成 zip 也能看）；不在同一个盘上时写 `file:///` 完整路径。
  截图不复制；PNG 已经被删了的照样写这个链接。
- 读不出来的记录：一节，写文件名和原文。

## 主进程多做的事（方案第 4 节"选区反馈、F8 界面问题 · Mori · 记录、收件箱、导出"，第 6 节 `feedback.ts`）

| 通道 | 做什么 |
| --- | --- |
| `mori:review-list` | 读 `feedback/` 和 `ui-issues/`，返回两类记录（读不出来的带原文） |
| `mori:review-shot` | 读一份报告的 PNG，交给界面显示（只接受 `ui-issues` 里报告时间格式的 `.png`） |
| `mori:review-export` | 弹保存对话框，按界面交来的记录名和已处理标记写导出文件 |

| `mori:review-show-record` | 在资源管理器里选中一份记录（详情里的"打开所在文件夹"；只接受这一类文件夹里的记录文件名） |

## 反例

- 打开工作回顾、标已处理、导出都不改反馈和报告文件，不发任何东西给模型或后台进程。
- 导出不复制截图，也不在 `ui-issues` 之外留下别的文件（除了你选的那一个 `.md`）。
- 回复不在了时不跳到会话底部假装找到了；原会话已删除时不新建会话。
- "隐藏已处理"开着时标了已处理，详情不会跟着消失（可以马上"标为未处理"）。
