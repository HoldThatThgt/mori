# 报告界面问题（F8，M2）

依据：方案 5.1（左栏底部入口）、5.15、第 6 节 `feedback.ts`。M7 的"界面问题"收件箱读取这里保存的文件。

## 入口

| 入口 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| F8 | 你按了 F8；首次启动页、设置页、会话里都有效，焦点在输入框里也有效 | 先截下当前窗口，再打开报告框（截图里没有报告框本身） | — |
| 左栏底部"报告界面问题（F8）" | 你点了它；左栏收起为图标栏时是一个图标按钮，悬停显示同一段文字 | 同上 | — |
| 已经开着报告框时再按 F8 | — | 不重复打开，焦点回到报告框的第一个输入框 | — |

后台进程退出后也能报告：截图和保存都在主进程里完成，不经过 pi。

## 报告框

| 状态 | 来源 | 必须可见 | 可做的操作 |
| --- | --- | --- | --- |
| 截图中 | 你按了 F8，主进程 `capturePage` 还没返回 | 什么都不显示（报告框要等截图完成才出现，免得截进图里），通常不到一秒 | Esc 取消 |
| 截图失败 | `capturePage` 报错 | 错误原文；仍可填写和保存（不带截图，文件里注明"截图失败：原文"） | 填写、保存、关闭 |
| 填写中 | 截图完成 | 截图缩略图；两个输入框"哪里不对"和"你期望什么"；说明"会附上截图、当前界面和最近的操作记录，保存在本机，不会发给模型" | 输入；保存（两个框都空时不可用）；关闭（Esc 或"取消"） |
| 保存中 | 你点了"保存" | 按钮显示"保存中…"，不可再点；"取消"和 Esc 都不起作用，等保存结束（免得看不到保存结果） | — |
| 已保存 | 主进程写完文件 | "已保存到 <Markdown 文件路径>"；"打开所在文件夹"；"在工作回顾中查看"（M7）；"关闭" | 打开所在文件夹（资源管理器里选中这个文件）；在工作回顾中查看（关闭报告框，打开工作回顾的"界面问题"并选中这一份，见 [review.md](review.md)）；关闭 |
| 保存失败 | 主进程写文件报错 | 错误原文；已输入的文字都还在 | 再保存；关闭 |

- 报告框是浮层，在所有菜单和对话框之上（例如开着"切换到全部允许？"时按 F8）：Esc 先关闭它（方案 5.8 的 Esc 顺序），不会停止生成；
  开着时 Alt+1 / Alt+2 / Alt+3 不会答复后面的批准卡。
- 打开报告框不影响正在生成的会话；关闭报告框后焦点回到打开前的位置。
- 没有填写就关闭时直接关闭；填写了一半关闭时也直接关闭（只是界面问题记录，不做草稿保存）。

## 保存的内容

保存在 `<userData>/ui-issues/`（临时默认值，见 defaults.md）：

- `<时间>.md`：时间格式 `YYYY-MM-DD-HHmmss`（本地时间），同一秒内再保存时加 `-2`、`-3`。
- `<时间>.png`：报告框打开前的窗口截图；Markdown 里用相对路径引用它。

Markdown 的结构（标题用中文，M7 按这些标题读取）：

| 一节 | 内容 | 来源 |
| --- | --- | --- |
| `# 界面问题 · <本地时间>` | 标题 | 保存时刻 |
| `## 哪里不对` | 你写的原文 | 你的输入 |
| `## 你期望什么` | 你写的原文；没写时为"（没有填写）"（"哪里不对"也一样，M7 对照代码时补记）。M7 起，你写的行里像 Markdown 标题的（以 `#` 到 `######` 加空格开头）前面加 `\`，工作回顾按标题切节时不会被它切错 | 你的输入 |
| `## 截图` | `![截图](<时间>.png)`；截图失败时写"截图失败：原文" | 主进程 `capturePage` |
| `## 当前界面` | 页面（首次启动 / 会话 / 设置 / 工具 / 工作回顾）、当前会话的名字、文件夹、会话文件、模型、是否在生成、阶段行文字、等你批准的数量（协作模式：见 docs/specs/parallel-agents-taskboard.md §11.3：计入后台实例的批准卡）、权限（每次询问 / 全部允许）、右栏是否打开、窗口大小、左右栏宽度、后台进程状态 | 界面状态（store）与窗口大小 |
| `## 最近的操作` | 最近 30 条操作，每条带时间：发给后台进程的命令（只写类型和不含机密的摘要，例如发送的前 40 个字、批准的选择；连接表单只写"保存连接"，不写 key）、页面切换、按 Esc 停止、批准卡的选择（协作模式：见 docs/specs/parallel-agents-taskboard.md §13.10：`session.setTeam` 记 `Team <mode>`，`session.recheckAgents` 记 `Check agent files`，`session.stopTeam` 记 `Stop team`，带 `team: 'once'` 的发送记 `Send (team): <摘要>`，`board.get` 不记） | 界面里的操作记录（只在本次运行的内存里） |
| `## 版本` | Mori 版本、Electron、Chromium、Node、Windows 版本 | 主进程 |

API key 在任何情况下都不写进报告。

反例：截图里不出现报告框；连接表单里填过的 key 不出现在"最近的操作"里；按 F8 不会让正在生成的会话停止。
