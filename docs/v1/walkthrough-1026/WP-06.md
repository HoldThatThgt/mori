## 负责人原话与改了什么

> instead of "new session" button, add a + icon next to the project title on the right

照 Claude 桌面版：侧栏每个项目行右端一个 +，点了在这个项目里新建会话；展开的左栏顶部的"New session"主按钮（连同它旁边的
"Ctrl+N"）去掉。Claude 的 + 在分组或文件夹的标题行上，读屏名 "New session in {folder}"（`nhF3HDb5P9`；另有
"New session in {group}"，`OdF0kukLHe`，Mori 的项目行是文件夹，所以用前一条），Claude 的提示里也写
"click the `+` next to one to start a session there"。

- 项目行：文件夹图标、文件夹名（悬停是完整路径）、右端一个淡色的 +，读屏名和悬停 "New session in <文件夹名>"。
  + 一直显示，悬停时变深；项目名放不下时先截项目名，+ 不挤出去；项目行不变高、文字仍只有文件夹名。
- 点 +：先过离开确认（AGENTS.md 或记忆页表单有未保存的改动时；"Keep editing"时什么都不变）；再在这个项目里新建会话
  （`session.create`，需要时先问信任），放进焦点所在的那一栏并切过去，名为 "New session"，焦点在输入框；窄窗口下浮动展开的
  左栏随之收起；在设置页、Customize、记忆页点时也回到会话面板。操作记录 "New session"（同原来的按钮），后台进程那一条
  "New session in <dir> …" 不变。
- 键盘：+ 不是 Tab 停靠点（`tabIndex` -1），键盘新建会话仍是 Ctrl+N（在当前会话所在的项目里）。走查 2 的 Shift+Tab 次数不变。
- 后台进程退出后：每个项目行的 + 不可用，悬停 "Mori’s background process crashed. Restart it to continue."（同左栏别的入口）。
- 收起为图标栏时：图标栏没有项目行，所以保留最上面那个 +（读屏名和悬停 "New session (Ctrl+N)"，样子不变），同 Ctrl+N；
  展开的左栏里没有它。
- 会话树里没有会话行可以放焦点时（归档、删除了最后一个），焦点移到左栏的 "Open folder…"（原来是 "New session"）。

代码：`state/projects.ts` 新加 `newSessionIn(cwd, leaving)`；`components/SessionTree.tsx` 新加 `ProjectHeading`（项目行和 +）、
`GroupProps`，焦点兜底改到 `nav-open-folder`，导出 `CRASHED_HINT` 给 `Sidebar.tsx` 共用；`components/Sidebar.tsx` 的
`SidebarNav` 只在收起时画 +（`rail-new-session`），"Open folder…" 加 `data-testid="nav-open-folder"`；`styles/layout.css` 加

文档：`docs/v0/screens/sessions.md`（"左栏"、会话树状态表、会话行、新一节"项目行的 +"、键盘、"打开、新建与切换"、归档与删除后的

## 按推荐替负责人定下的

诊断的三个问题，第 1 个按走查记录（不是诊断的推荐），后两个按推荐：

1. 顶部的 "New session" 是否全去掉：展开的左栏里去掉，收起的图标栏保留一个 +。走查记录写"收起的侧栏保留一个 +"
   （诊断推荐的是全部去掉；图标栏没有项目行，不留它就没有用鼠标新建会话的地方）。
2. + 什么时候显示：一直显示，淡色（`--color-faint`），悬停时变深（`--color-text`）。Claude 的 + 是否只在悬停时出现没有确认。
3. 能不能用键盘到每个项目的 +：不能，只用鼠标；键盘用 Ctrl+N。会话树整棵一个 Tab 停靠点不变。

实现时另外定的（临时，登记在 `docs/v0/defaults.md`"项目行的 +"）：

4. 用 Claude 的 "New session in {folder}"，`<folder>` 是项目行显示的文件夹名（不是完整路径；完整路径仍在项目行的悬停里）。
5. 点 + 打开到焦点所在的那一栏（同 Ctrl+N，`split.md`）；确认可以离开之后才收起浮动的左栏、把焦点交给新会话的输入框
   （同点会话行的做法：选 "Keep editing" 时浮动的左栏不收起）。
6. 上一个新会话还在 "Starting…" 时 + 照常可用（同原来的 "New session" 按钮；只有 Ctrl+N 有这条限制）。
7. 焦点兜底用左栏 "Open folder…" 的新标识 `nav-open-folder`，不用 `open-folder`（中栏 "Open a folder" 页上的按钮在用，WP-01 的测试靠它）。
8. 图标栏的 + 样子不变（`.nav-item.primary` 的浅蓝底），读屏名不变；标识改成 `rail-new-session`（只在收起时有，与原来两种状态都有的
   `new-session` 区分开）。
9. 后台进程退出时的悬停文字在 `SessionTree.tsx` 定一个常量 `CRASHED_HINT`，左栏导航和项目行共用（别处已有的同一句不动）。
10. "Open folder…"、"Loading sessions…"、"没有会话"这些状态的可做操作里去掉 "New session"，只写 "Open folder…"。

还要走查时确认：跨组计划（`plan1.json` 的 gaps 与 WP-06 的理由）提到，"next to the project title" 也可能指顶栏的项目名
（`ChatPane.tsx` 的 "项目名 › 会话名"），这里按侧栏的项目行做（与 Claude 相同）。
