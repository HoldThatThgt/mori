是 model-facing：选择器少了一步，会话第一次选模型、出故障后换模型、压缩、增强任务与平行 Agent 的角色选到哪个模型会变；

## 改了什么、为什么

负责人不要区分本机、内网和公网的模型。原来的规则（proposal §12 第 2 行“公网提供商默认不允许，只能在本机按项目授权”）
整个推翻，界面、配置、命令、选择器里关于区域的部分都删掉，不留兼容层。

| 原来 | 现在 |
| --- | --- |
| 每个提供商有网络区域（Local / Intranet / Public，`providers[].zone`）；全局允许的区域 `allowedZones`（默认 Local、Intranet），按项目放宽 `projectZones` | 都删掉。任何提供商都可以在任何项目里用；会话的范围（分组，以及项目的 `.mori/models.json` 把分组缩小）是唯一的限制 |
| 选择器第 2 步按区域排除候选（`zone_unconfirmed`、`zone_blocked`） | 第 2 步删掉，其余各步编号不变（第 1、3 步仍是静态校验） |
| 拒绝启动卡 `no_candidate` 有“Allow <zone> for this project”“Confirm zone” | 只有 Verify now、Change model…、Open settings |
| 设置 → Models：区域未确认的几行与确认对话框、Defaults 的“Allowed zones for all projects”、提供商卡的“Network zone”、Add provider 与 Edit 的 Network zone 单选和区域建议、Project access 一节（项目列表、放宽区域、Public 的确认框、项目配置的错误） | 都删掉。Models 从上到下是迁移说明 → Defaults → Providers → Groups |
| 首次启动表单有 Network zone，选 Public 时说明“Public providers must be allowed per project”；公网地址的第一个会话要在拒绝启动卡上授权 | 没有区域；测试连接成功、打开文件夹就能发送 |
| 范围菜单每项右侧标区域；范围按钮悬停第二行“<提供商名> · <区域>”，读屏的描述“<提供商名>, <区域>” | 每项只写名字；悬停第二行与读屏的描述只有提供商名 |
| 从 v0 迁移时按地址建议区域，确认前被排除 | 迁移来的提供商马上可以用 |
| 项目的 `.mori/models.json` 可以写 `allowedZones` | 只有 `groups`；写了 `allowedZones` 按未知字段报 `project_config` |

还写着这三个字段的 `model-config.json`：严格校验按未知字段报错（不写兼容代码），设置 → Models 只显示
“Couldn’t read model settings: <路径>: …”，原文里有 `providers.0: Unrecognized key: "zone"` 和
`Unrecognized keys: "allowedZones", "projectZones"`，加“Retry”；会话按 `config_invalid` 拒绝启动。把字段从文件里删掉后点 Retry。

## 给负责人

1. **后果**：会话、压缩、增强任务、平行 Agent 的 task agents 与自动换模型，都可能把项目的代码发给范围里的任何一个提供商，
   包括公网上的（DeepSeek、z.ai、OpenRouter 等）。要限制一个项目只用某几个提供商，只能用分组和项目的 `.mori/models.json`
   （把分组缩小到其中一部分）。
2. 你安装版的 `model-config.json`（`%APPDATA%\Mori`）里还写着这三个字段。装新版之前要备份后删掉一次（由 lead 做，这个包
   没有碰安装版的数据）；不删的话新版打开后 设置 → Models 只显示“Couldn’t read model settings…”，会话都被拒绝启动。
3. 某个项目的 `.mori/models.json` 如果写了 `allowedZones`，这个项目里的会话会被拒绝启动（`project_config`，卡上写出原文），
   删掉这个字段即可。原来 Project access 里也列出项目配置的错误，现在只在会话的拒绝启动卡上看得到。
4. 范围菜单与范围按钮的悬停不再写区域；拒绝启动卡不再有“Allow <zone> for this project”“Confirm zone”。
